# Use forward simulation for forecasts and action comparisons

PulseAhead will run many plausible futures from the observed ED state to estimate congestion risk and timing. The same flow model will compare staff-approved actions, keeping staffing, treatment spaces, diagnostics, ward capacity, and transport constraints consistent. The working simulation, action comparison, and measured evidence take priority; a learned risk model is optional afterward if it adds measured value. The demo uses disclosed synthetic assumptions; real hospital data and validation are future work.
